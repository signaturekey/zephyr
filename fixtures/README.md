# Golden-сценарии Zephyr

В `golden/` находятся двенадцать обязательных сценариев MVP из раздела 26.2
`AGENTS.md` и дополнительные сценарии TypeScript/frontend, `SKILL.md`,
reliability, messaging, infrastructure и storage. В каждом
каталоге лежит один самодостаточный
`fixture.json`, содержащий:

- файлы репозитория и необязательный план, из которых строится immutable packet;
- candidate findings в JSON от изолированных reviewer-ролей;
- вердикты evidence-gate;
- точный агрегированный результат, ожидаемый от детерминированного core.

Сценарии не вызывают LLM, MCP-серверы, сетевые сервисы и не используют Git-конфиг
разработчика. Тест создаёт временную структуру репозитория, проверяет документы
candidate и verdict по встроенным JSON Schema, запускает стандартный
детерминированный routing, evidence precheck и aggregation, а затем проверяет
стабильный Markdown-рендеринг. У каждой выбранной роли есть отдельный envelope;
роль без замечаний возвращает валидный пустой массив `findings`.

Запустить только golden-набор можно командой:

```bash
go test ./fixtures/...
```

При намеренном изменении протокола сначала обновите schema/core, затем вручную
измените явный ожидаемый результат затронутого сценария. Никогда не генерируйте
golden-ожидания из той же реализации, которую они должны проверять.
